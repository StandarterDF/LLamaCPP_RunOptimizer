# .opencode — конфигурация агента

Настройки OpenCode для этого репозитория: слэш-команды и скилы, которыми выполняются исследования
(замеры, RP-оценка, отбор моделей). Общие правила проекта — [AGENTS.md](../AGENTS.md).

## Команды

| Файл | О чём |
| --- | --- |
| [commands/current-best.md](commands/current-best.md) | Команда: собрать текущую «лучшую» рекомендацию (модель/конфиг). |

## Скилы

| Скил | Для чего |
| --- | --- |
| [skills/llm-launch-tuner](skills/llm-launch-tuner/SKILL.md) | Подбор конфига запуска GGUF: инвентарь железа, серии бенчмарков, тюнинг KV/спекуляции; результат — `.bat` + FINDINGS/LAUNCH. |
| [skills/rp-model-eval](skills/rp-model-eval/SKILL.md) | Прогон и оценка RP-качества: suite → генерация → панель 4 судей → сводка и реестры. |
| [skills/gemma4-ru-rp-researcher](skills/gemma4-ru-rp-researcher/SKILL.md) | Поиск и отбор готовых Gemma-4-файнтюнов под русский RP (фильтры по базе, кванту, контексту). |

Скилы подхватываются OpenCode автоматически (по описанию задачи); порядок работы описан в каждом
`SKILL.md`.
