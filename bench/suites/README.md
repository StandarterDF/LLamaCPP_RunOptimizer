# bench\suites — наборы тестов для bench.py

JSON-серии запросов (промпты + параметры), которые прогоняет [bench\bench.py](../bench.py).
Числа попадают в [bench\runs](../runs/README.md) (TG/PP, время, VRAM). В итоговые таблицы идут
только серии на реалистичных промптах ([requests_real.json](../requests_real.json)); «тест-заполнитель»
(`target`) годится лишь как стресс-тест и завышает TG в 1.5–2 раза.

| Папка | О чём |
| --- | --- |
| [real](real) | Реалистичные серии по моделям (RP/чат/код/математика/суммаризация) — основа замеров. |
| [spec](spec) | Спекуляция: без/MTP/DFlash, nmax, pmin — что окупается на каких задачах. |
| [tune](tune) | Тюнинг флагов: KV, ngram, DFlash, температура, RP-пресеты. |
| [kv](kv) | KV-кэш: расчётные и промптовые серии. |
| [audit](audit) | Аудит сборок (например, MTP на старой и новой версии llama.cpp). |
| [probe](probe) | Пробы: глубина контекста, мультитёрн, переполнение, vision. |
| [once](once) | Разовые серии (baseline, финальные прогоны, старые тюнинги). |

Запуск: `bench.py --suite bench\suites\real\real_<модель>.json` (подробнее — в шапке скрипта).
