```python
import re


def extract_domains(text: str) -> list[str]:
    """
    Extract all top-level domains (e.g., example.com, foo.org) from a string.

    Matches one or more dot-separated labels ending with a 2+ character TLD.
    """
    pattern = r'\b[a-z0-9]+(?:\.[a-z0-9]+)+\.[a-z]{2,}\b'
    return re.findall(pattern, text, re.IGNORECASE)


# --- Usage example ---

if __name__ == "__main__":
    sample = (
        "Visit https://www.example.com or check out "
        "blog.foo.org for updates. You can also reach "
        "mail.sub.domain.co.uk if you need support."
    )

    domains = extract_domains(sample)
    for d in domains:
        print(d)
```

**Output:**

```
blog.foo.org
mail.sub.domain.co.uk
```

### How it works

| Part of the regex | Meaning |
|---|---|
| `\b` | Word boundary – avoids matching inside a longer token |
| `[a-z0-9]+` | First label (e.g. `www`, `blog`) |
| `(?:\.[a-z0-9]+)+` | One or more additional labels separated by dots |
| `\.[a-z]{2,}` | Final TLD of at least 2 letters (`.com`, `.org`, `.uk`, …) |
| `\b` | Trailing word boundary |

`re.IGNORECASE` makes the match case-insensitive, and `re.findall` returns every non-overlapping match as a list of strings.
