# Finding x³ + 1/x³ given x + 1/x = 3

## Step 1: Square both sides

$$(x + \tfrac{1}{x})^2 = 3^2$$

$$x^2 + 2\cdot x \cdot \tfrac{1}{x} + \tfrac{1}{x^2} = 9$$

$$x^2 + 2 + \tfrac{1}{x^2} = 9$$

$$x^2 + \tfrac{1}{x^2} = 7$$

## Step 2: Use the cube identity

Expand $(x + \frac{1}{x})^3$ using the binomial formula:

$$\left(x + \tfrac{1}{x}\right)^3 = x^3 + 3x^2\!\cdot\!\tfrac{1}{x} + 3x\!\cdot\!\tfrac{1}{x^2} + \tfrac{1}{x^3}$$

$$= x^3 + \tfrac{1}{x^3} + 3\!\left(x + \tfrac{1}{x}\right)$$

Rearranging:

$$x^3 + \tfrac{1}{x^3} = \left(x + \tfrac{1}{x}\right)^3 - 3\!\left(x + \tfrac{1}{x}\right)$$

## Step 3: Substitute

$$x^3 + \tfrac{1}{x^3} = 3^3 - 3(3) = 27 - 9$$

$$\boxed{x^3 + \dfrac{1}{x^3} = 18}$$
