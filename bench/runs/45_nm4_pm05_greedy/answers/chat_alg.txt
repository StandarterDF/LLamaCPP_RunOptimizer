```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_start, last_end = merged[-1]
        if start <= last_end:
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))

    return merged
```

Algorithm: sort intervals by start time, then scan once, extending the last merged interval when the next interval overlaps; otherwise start a new merged interval.

Complexity: `O(n log n)` time due to sorting, `O(n)` space for the result.
