To find the value of $x^3 + \frac{1}{x^3}$ given that $x + \frac{1}{x} = 3$, we can use the algebraic identity for the cube of a binomial.

**Step 1: Identify the relevant identity**
The formula for $(a + b)^3$ is:
$$(a + b)^3 = a^3 + b^3 + 3ab(a + b)$$

**Step 2: Substitute the given values into the identity**
Let $a = x$ and $b = \frac{1}{x}$.
$$(x + \frac{1}{x})^3 = x^3 + \left(\frac{1}{x}\right)^3 + 3(x)(\frac{1}{x})(x + \frac{1}{x})$$

**Step 3: Simplify the identity**
Note that $x \cdot \frac{1}{x} = 1$. The equation becomes:
$$(x + \frac{1}{x})^3 = x^3 + \frac{1}{x^3} + 3(x + \frac{1}{x})$$

**Step 4: Substitute the known value**
We are given that $x + \frac{1}{x} = 3$. Plug this value into the equation:
$$(3)^3 = x^3 + \frac{1}{x^3} + 3(3)$$

**Step 5: Solve for $x^3 + \frac{1}{x^3}$**
Calculate the powers and the product:
$$27 = x^3 + \frac{1}{x^3} + 9$$

Subtract 9 from both sides:
$$27 - 9 = x^3 + \frac{1}{x^3}$$
$$18 = x^3 + \frac{1}{x^3}$$

**Final Answer:**
x^3 + 1/x^3 = 18
