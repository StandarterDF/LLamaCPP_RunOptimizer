To extract domain names from a text, we can use a regular expression that looks for sequences of alphanumeric characters followed by a dot and a recognized top-level domain (like `.com`, `.org`, `.net`, etc.).

Here is the complete solution:

```python
import re

def extract_domains(text):
    """
    Extracts top-level domains (e.g., example.com) from a string.
    This regex looks for words followed by a dot and a common TLD.
    """
    # Regex explanation:
    # [a-zA-Z0-9-]+ : Matches letters, numbers, and hyphens (the domain name)
    # \.            : Matches a literal dot
    # [a-zA-Z]{2,}  : Matches the TLD (at least 2 letters, e.g., .com, .org, .edu)
    domain_pattern = r'[a-zA-Z0-9-]+(?:\.[a-zA-Z0-9-]+)*\.[a-zA-Z]{2,}'
    
    return re.findall(domain_pattern, text)
