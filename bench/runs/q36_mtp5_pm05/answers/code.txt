   - Steps:
     1. If the list is empty, return it.
     2. Sort intervals based on start time.
     3. Initialize a result list with the first interval.

        - Otherwise, append the current interval to the result list.
     5. Return the result list.
   - Time Complexity: O(n log n) due to sorting, where n is the number of intervals. The merging step is O(n).
