```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals = sorted(intervals)
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_end = merged[-1][1]
        if start <= last_end:
            merged[-1] = (merged[-1][0], max(last_end, end))
        else:
            merged.append((start, end))

    return merged
```

Algorithm: sort intervals by start time, then iterate and extend the last merged interval when the next interval overlaps; otherwise start a new merged interval.

Complexity: `O(n log n)`
