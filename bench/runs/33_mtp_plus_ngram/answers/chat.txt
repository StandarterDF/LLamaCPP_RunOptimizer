```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last = merged[-1]
        if start <= last[1]:
            last[1] = max(last[1], end)
        else:
            merged.append([start, end])

    return merged
```

Algorithm: sort intervals by start time, then scan and merge whenever the next interval’s start is at most the current merged interval’s end. Complexity is dominated by sorting: O(n log n).
