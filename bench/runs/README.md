# bench\runs — результаты скоростных прогонов

Всё, что пишет [bench.py](../bench.py) и собирает [report.py](../report.py):

| Файл / папка | О чём |
| --- | --- |
| `results.jsonl` | Машиночитаемые записи по каждому прогону (модель, серия, TG/PP, спекуляция, VRAM). |
| `summary.md` | Человекочитаемая сводка результатов (генерируется report.py). |
| `NN_<тема>/` | Папки серий по порядку запуска: `server.log` и сопутствующие файлы. |

Папки — история экспериментов (включая отброшенные гипотезы): по ним видно, что и зачем проверялось.
В итоговые таблицы и README попадают только проверенные числа из `results.jsonl` и логов моделей
в [docs\models](../../docs/models/README.md).
