Here is the Python implementation for merging overlapping intervals:

```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # 1. Sort intervals based on the starting value
    intervals.sort(key=lambda x: x[0])

    merged = [intervals[0]]

    for current in intervals[1:]:
        last_merged = merged[-1]

        # 2. If current interval overlaps with the last merged one, merge them
        if current[0] <= last_merged[1]:
            last_merged[1] = max(last_merged[1], current[1])
        else:
            # 3. Otherwise, add the current interval as a new entry
            merged.append(current)

    return merged

# Usage Example
example_input = [[1, 3], [2, 6], [8, 10], [15, 18]]
print(f"Input: {example_input}")
print(f"Merged: {merge_intervals(example_input)}")
```

### Explanation
The algorithm first sorts the intervals by their start times to ensure that overlapping intervals are adjacent. It then iterates through the list, either extending the end time of the last interval if an overlap is detected or adding it as a new entry if no overlap exists.
