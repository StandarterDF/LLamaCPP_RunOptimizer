```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_start, last_end = merged[-1]
        if start <= last_end:
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))

    return merged
```

The algorithm sorts intervals by start time, then scans them once, merging whenever the next interval overlaps the current merged interval.  
Complexity: **O(n log n)** time due to sorting, **O(n)** space for the merged result.
