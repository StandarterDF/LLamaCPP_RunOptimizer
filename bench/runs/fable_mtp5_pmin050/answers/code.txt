Here’s a concise implementation plus explanation and example.

Code:

def merge_intervals(intervals):
    if not intervals:
        return []
    intervals.sort(key=lambda x: x[0])
    merged = []
    for start, end in intervals:
        if not merged or start > merged[-1][1]:
            merged.append([start, end])
        else:
            merged[-1][1] = max(merged[-1][1], end)
    return merged

Explanation and complexity:

The algorithm sorts intervals by start time, then iterates through them, merging each interval with the last merged interval if they overlap; otherwise it starts a new interval. Sorting dominates the cost, so the time complexity is O(n log n), and the space complexity is O(n) for the output list.

Usage example:

intervals = [[1, 3], [2, 6], [8, 10], [15, 18]]
print(merge_intervals(intervals))
# Output: [[1, 6], [8, 10], [15, 18]]
