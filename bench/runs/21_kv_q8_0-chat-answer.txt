```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_start, last_end = merged[-1]
        if start <= last_end:
            merged[-1] = [last_start, max(last_end, end)]
        else:
            merged.append([start, end])

    return merged
```

Algorithm: sort intervals by start time, then scan once, merging each interval into the previous one if it overlaps or touches.  
Complexity: O(n log n) from sorting, O(n) for merging
