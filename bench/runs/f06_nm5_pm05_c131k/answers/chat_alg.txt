```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last = merged[-1]
        if start <= last[1]:
            last[1] = max(last[1], end)
        else:
            merged.append([start, end])

    return merged
```

The algorithm sorts intervals by start time, then scans them once, merging any interval that starts before or at the end of the previous merged interval. Sorting takes O(n log n), and the merge pass takes O(n), so the total complexity is O(n log n).
