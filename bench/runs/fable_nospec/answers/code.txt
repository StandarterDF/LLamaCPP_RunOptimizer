Here’s a concise Python implementation, followed by a brief explanation and example.

```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # Sort intervals by start time
    intervals.sort(key=lambda x: x[0])

    merged = []
    for start, end in intervals:
        # If there's no overlap or merged list is empty, add current interval
        if not merged or start > merged[-1][1]:
            merged.append([start, end])
        else:
            # Overlap exists: extend the end of the last interval
            merged[-1][1] = max(merged[-1][1], end)

    return merged
```

Algorithm explanation:
- Sort intervals by start time, then iterate through them, merging each interval with the last merged interval whenever they overlap (i.e., when the current start is less than or equal to the last end).
- This greedy approach works because sorting ensures any overlaps are adjacent, allowing a single pass to combine them correctly.

Time complexity:
- Sorting dominates the cost at O(n log n), and the subsequent linear scan is O(n), so overall time complexity is O(n log n).
