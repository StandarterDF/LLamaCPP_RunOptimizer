```python
import re


def extract_domains(text: str) -> list[str]:
    """Extract all top-level domains (e.g. example.com) from a string.

    Matches patterns like:
        example.com
        sub.domain.co.uk
        my-site.org
    """
    pattern = r'\b[a-zA-Z0-9](?:[a-zA-Z0-9-]*[a-zA-Z0-9])?(?:\.[a-zA-Z0-9](?:[a-zA-Z0-9-]*[a-zA-Z0-9])?)*\.[a-zA-Z]{2,}\b'
    return re.findall(pattern, text)


# --- Usage Example ---

sample_text = """
Check out https://www.example.com for details.
Also visit blog.subdomain.co.uk and api.my-service.org.
The email at user@company.io was sent from server.internal.example.
"""

domains = extract_domains(sample_text)
print("Extracted domains:")
for d in domains:
    print(f"  {d}")
```

### How the regex works

| Fragment | Meaning |
|----------|---------|
| `\b` | Word boundary (avoids matching inside larger words) |
| `[a-zA-Z0-9]` | First label must start with alphanumeric |
| `(?:[a-zA-Z0-9-]*[a-zA-Z0-9])?` | Remaining chars of that label (allows hyphens) |
| `(?:\.[a-zA-Z0-9](?:[a-zA-Z0-9-]*[a-zA-Z0-9])?)*` | Zero or more additional labels (handles subdomains) |
| `\.[a-zA-Z]{2,}\b` | Final TLD must be ≥ 2 letters (e.g. `.com`, `.co.uk` → the last `.uk`) |

> **Note:** For `.co.uk`-style multi-part TLDs, the regex captures the full domain (`subdomain.co.uk`) because the last label must be purely alphabetic and ≥ 2 chars, which naturally stops at the TLD boundary.
