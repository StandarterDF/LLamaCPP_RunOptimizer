2.  **Algorithm Design (Merging Intervals):**
   - Standard approach: Sort intervals by start time.
   - Iterate through sorted intervals, maintaining a result list.
   - For each interval, check if it overlaps with the last interval in the result list.
   - If overlap exists (current start <= last end), merge by updating the end to max(last end, current end).
   - If no overlap, append the current interval to the result list.
   - Time Complexity: O(n log n) due to sorting, where n is the number of intervals. The merging pass is O(n).
   - Space Complexity: O(n) for the result list (or O(1) extra if modifying in place, but typically we return a new list).
