```python
def merge_intervals(intervals):
    if not intervals:
        return []

    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]

    for start, end in intervals[1:]:
        last_end = merged[-1][1]
        if start <= last_end:
            merged[-1] = [merged[-1][0], max(last_end, end)]
        else:
            merged.append([start, end])

    return merged
```

Sort intervals by start time, then scan and merge whenever an interval starts before or at the end of the previous interval. Complexity: `O(n log n)` due to sorting, and `O(n)` for the merge pass.
