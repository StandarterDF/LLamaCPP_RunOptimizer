# runs — результаты прогонов и судейства

Папки на каждый прогон; имя = `<этап>_<модель>_<режим>[-<штамп>]`.

| Что | О чём |
| --- | --- |
| `rp_eval_*/` | Прогон модели: `metrics.jsonl` + `raw/` (очищенные ответы) + `raw_full/` (сырой текст с thinking). |
| `rp_judge*/` | Судейство: пакеты `__part*.txt`, `judge_server.log` (локальные судьи). |
| `_panel/` | Панель 4 судей: `pack_*.txt`, `PROMPT.txt`, `votes/` (голоса облачных судей). |
| `matrixA_*`, `artemis31_ru`, `darkthoughts_ru`, `baseline_repro` | Ранние серии (до стандартизации имён). |

Человекочитаемые выводы живут в [docs\quality](../../../docs/quality/README.md); здесь — сырьё,
его не переписываем и не чистим. Побочные логи `_*.log` в git не попадают.
