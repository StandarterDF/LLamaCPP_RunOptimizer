# prompts — сценарии и промпты

| Файл | О чём |
| --- | --- |
| [scenarios_rp.json](scenarios_rp.json) | Скрин: 2 сценария (school + seduction) — базовый набор для любой модели. |
| [scenarios_rp_full.json](scenarios_rp_full.json) | Полный набор: 6 сценариев — только для лидеров скрина. |
| [scenarios_rp_en.json](scenarios_rp_en.json) | Английская версия сценариев (EN-скрин). |
| [prompts_ru_rp.json](prompts_ru_rp.json) | RU-промпты для языковых проверок в харнессе. |
| [prompts_ru_smoke.json](prompts_ru_smoke.json) | Короткий смоук-набор для быстрой проверки русского. |

Сценарий = карточка персонажа + первое сообщение + ходы; финальный ход требует продолжить сцену,
вспомнить факт и принять решение. Из этих файлов генерируются наборы в [suites](../suites/README.md).
