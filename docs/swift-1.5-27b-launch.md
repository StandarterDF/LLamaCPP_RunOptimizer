# Как запускать Swift-1.5-Qwen3.8-27B (IQ2_S-mtp) — итоговая инструкция

Всё проверено на локальных билдах llama.cpp. **Актуальная рекомендация (05.10.2026): сборка b11382
(CUDA 12.4) даёт +10…18 % к скорости** — готовый запуск в `launch\b11382-cu124\swift-best-b11382.bat`
(там `--load-mode none` вместо удалённого `--no-mmap`). Конфиг ниже — база, проверенная на обоих билдах.
Подробные замеры и обоснования — в `swift-1.5-27b.md`, сравнение сборок — в `speculation-research.md`.
Готовые файлы запуска — в `launch\b11382-cu124\`.

## 1. Основной профиль (рекомендуется)

```bat
<папка llama.cpp>\llama-server.exe ^
  -m "<папка моделей>\ukisai\Swift-1.5-Qwen3.8-27B-GSQ-RCO-GGUF\Swift-1.5-Qwen3.8-27B-GSQ-RCO-IQ2_S-mtp.gguf" ^
  --host 0.0.0.0 --port 9931 --alias "Swift-1.5-27B" ^
  --parallel 1 -c 81920 ^
  -fa on --fit on --no-mmap ^
  -ctk q4_0 -ctv q4_0 ^
  --spec-type draft-mtp --spec-draft-n-max 5 --spec-draft-n-min 1 --spec-draft-p-min 0.5 ^
  --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0 --presence-penalty 0.0 --repeat-penalty 1.0 ^
  --reasoning-preserve
```

Ожидаемые показатели на RTX 4060 Ti 16 ГБ:

| Метрика | Значение |
| --- | --- |
| VRAM после загрузки | ~12.9–13.1 ГБ (запас ~3 ГБ) |
| Загрузка | ~3.5 с (`--no-mmap`, NVMe) |
| PP (prompt processing) | ~650 t/s; ~520–600 t/s на глубине 30–60k |
| Генерация, реальный чат (temp 1.0) | ~37–38 t/s в среднем (математика ~45, код ~31) |
| Генерация, простые продолжения | ~57 t/s |
| Генерация без MTP (для сравнения) | ~21 t/s |

## 3. Почему именно так

1. **MTP обязателен** (`--spec-type draft-mtp`, файл `-mtp`): +75 % генерации на реальном чате (21 → 37 t/s)
   и до 2.4× на простых продолжениях. Без него модель ~21 t/s.
2. **`--spec-draft-n-max 5 --spec-draft-p-min 0.5`** — лучший баланс по серии `tuning1/3/final1`.
   Высокий `p-min` (0.7–0.9) красиво повышает «принятие», но снижает итоговую скорость.
   При temp ≤0.3 хорошо и `n-max 4`.
3. **`-ctk q4_0 -ctv q4_0`**: экономия ~1.5–2 ГБ на 80k контекста. При этом **FlashAttention обязателен** —
   с `-fa off` сервер не стартует («quantized V cache requires flash_attn to be enabled»).
   Вариант `-ctk q8_0 -ctv q8_0` помещается до ~90k контекста (VRAM ~14.1 ГБ) — запас качества, скорость та же.
4. **`--fit on` (дефолт) + `-ngl auto`**: сервер сам размещает слои/буферы; проверено, меньше памяти, чем `--fit off`.
5. **`--no-mmap`**: загрузка ~3.5 с против ~5.5 с с mmap; на скорость не влияет. Эквивалент: `--load-mode none`.
6. **Батчи/потоки — дефолтные** (`-b 2048 -ub 512`, `-t 8`). `-ub 1024/2048` не ускоряют PP, только едят VRAM.
   `-tb 12` безвреден, но и бесполезен.
7. **128k контекста — не включать** (c=163840): грузится, но генерация падает до ~20 t/s.
   Практический максимум — **131072**, и там из-за роста стоимости драфтов лучше `nmax3, pmin0.7`.
8. **Сэмплинг — как в карточке модели** (temp 1.0 и т.д.). Пользовательский temp 0.3 тоже работает и даёт
   +5–8 % к скорости за счёт лучшего принятия черновиков; это компромисс «стабильность/скорость» против «креативности».

## 4. Мышление (reasoning)

- По умолчанию включено, `reasoning_effort = xhigh`. **Допустимы только `xhigh`, `medium`, `low`** —
  другие значения (`minimal`, `high`, `max`) вызывают ошибку шаблона.
- `--reasoning off` — отключает «мысли»: быстрее, но простые задачи могут решаться менее аккуратно.
- `--reasoning-preserve` — сохранять «мысли» в истории (полезно для мультитёрна/агентов).
- «Мысли» приходят отдельно — в `reasoning_content`, ответ — в `content`.

## 5. Чего избегать

| Не делать | Почему |
| --- | --- |
| `-fa off` | сервер не стартует с квантованным V-кэшем |
| `-ub 2048` / большие батчи | +1.2 ГБ VRAM, PP не растёт |
| `p-min 0.7–0.9`, `n-max ≥6` | видимое «принятие» растёт, итоговая скорость падает |
| `c ≥ 160k` | деградация генерации до ~20 t/s |
| Подключать чужой `mmproj` | авторы Swift не валидировали проектор для этого релиза; для текста он не нужен |
| Обновлять билд/модель из сети | запрещено правилами проекта (`AGENTS.md`) |

## 6. Известные ограничения текущего билда

- В build 10472 **нет CUDA-graphs для MTP-драфта** (появились в upstream после 17.08.2026, PR #28549).
  Это заложенный потолок скорости; обновление билда запрещено правилами.
- 27B-модель в IQ2_S на 4060 Ti: PP ~650 t/s — близко к пределу вычислений карты, ускорить флагами нельзя.
- KLD-таблица карточки: IQ3_XXS заметно точнее IQ2_S (0.098 против 0.135), но это другой файл (нет локально).

## 7. Как воспроизвести замеры

```powershell
cd <папка проекта>
.\.venv\Scripts\python.exe bench\bench.py bench\suites\final1.json          # отбор MTP
.\.venv\Scripts\python.exe bench\bench.py bench\suites\tuning2.json         # KV/FA/загрузка/потоки
.\.venv\Scripts\python.exe bench\bench.py bench\suites\quality1.json        # режимы мышления
.\.venv\Scripts\python.exe bench\report.py                                  # сводка
```

Сырые результаты: `bench\runs\results.jsonl`, логи серверов — `bench\runs\*.log`, ответы — `bench\runs\*-answer.txt`.
