# Облачные API-модели на RP: DeepSeek и GLM (2026-10-07)

Первая проверка **облачных** моделей нашим RP-харнессом. Сценарии локальные
(`bench\quality\prompts\scenarios_rp.json`, school + seduction), 3 сида, RU-safe сэмплинг
(temp 0.6 / top_p 0.95). Ответы идут через API, но метрики и судейство — штатные.

## Инструменты и режимы

| Что | Файл / флаг |
| --- | --- |
| Генерация через API (параллельно) | `bench\quality\api_rp_eval.py` (`--concurrency`) |
| Облачный судья (параллельно) | `bench\quality\api_judge.py` (`--all`, `--concurrency`) |
| Объективные метрики по API-прогонам | `bench\quality\api_metrics_summary.py` |
| Ключи | `.env` (gitignored; шаблон `.env.example`) |

Режим мышления: у DeepSeek и GLM thinking включён по умолчанию. Для сравнения с локальным
**nothink** он отключается (`"thinking": {"type": "disabled"}`), кроме **`glm-5.3` и
`glm-5.3-flash` — у них thinking форсированный** (z.ai: «always engages in thinking»), они идут
на `reasoning_effort: low` (каталог `_think`). DeepSeek: non-thinking тоже `thinking disabled`
(в этом режиме `temperature` учитывается, `top_p` фиксируется 1.0).

**glm-5.3-flash вставляет CJK прямо в русский текст**: «так что **的计划** не поддавайся»,
«Д**发达**ела», «Слух **bad**?»; **glm-5.3** — англ. кальки («не могла **retract'нуть**»). Оба —
именно форсированно-думающие. Остальные модели дали **100 % чистых** ответов по-русски.

## Выводы

1. **Облако — верхний уровень.** Все 12 моделей по мягкому судье (Gemma) в диапазоне **4.06–4.73** —
   выше локальных RP-мержей (4.24–4.38): GLM-5.3 = 4.73, DeepSeek-Pro = 4.71. По строгому Qwen
   лидеры — **GLM-4.7 (3.91)**, GLM-5 (3.75), DeepSeek-Flash (3.69).
2. **Судьи расходятся сильно** — это и есть главный урок. Пример: `GLM-5.3-Flash` у Gemma 4.40, у
   DeepSeek-Pro **4.08 (2-я в таблице)**, а у Qwen 3.42; `DeepSeek-Flash` у Qwen имел «повторы 1.5»,
   у DeepSeek — 4.8. Ранжировать «в общем» нельзя — только по колонке.
3. **DeepSeek-судья ставит себя №1** (self-eval): DeepSeek-Flash — лучший у DS-Flash (3.71) и у
   DS-Pro (4.38). Баллы DeepSeek по своим же моделям не считать независимыми.
4. **DeepSeek-судьи суровее к локальным Gemma-мержам**, чем Gemma/Qwen: DTV2, Schattenblume,
   Giftige-Blume получают у DS-Pro 3.3–3.7 против 4.2–4.6 у Gemma-судьи.
5. **Форсированный thinking дорого обходится языку**: только `glm-5.3`/`glm-5.3-flash` текут
   иероглифами/кальками; их «non-think» невозможен.
6. Практически: для русского RP из облака лучше всего **GLM-4.7/5.x и DeepSeek-Pro** (чисто,
   держат границы, поправляют ложные факты); дешёвые Flash-варианты (`glm-4.7-flashx`, `-flash`)
   заметно слабее.

Оговорки: облако (платно, сетевая задержка), reasoning-модели (не «настоящий» nothink), 2 сцены
(не полный набор), DeepSeek-строки — self-eval. Харнесс не измеряет «нравится» — только связность,
память, характер и язык.

## Локальные модели глазами DeepSeek-судей (2 сцены, NoThink)

DeepSeek-судьи прогнаны по **всем** прогонам; полная сводка — `bench\quality\judge_table.py`. Они
**суровее** к локальным, чем Gemma (пример, Flash / Pro): DTV2 **3.40 / 3.42**, Schattenblume
**3.18 / 3.40**, StyleTune **3.29 / 3.77**, Giftige-Blume **3.32 / 3.33**, Goetia **3.09 / 3.56**,
MeroMero **3.31 / 3.88**, base Gemma-26B **3.08 / 3.77**, Swift **2.54 / 3.29**, Artemis **2.40 / 2.92** —
против 4.2–4.5 у Gemma-судьи. Форма лидера сохраняется (DTV2/Schattenblume/StyleTune/MeroMero вверху),
но **разброс между судьями больше, чем разница между моделями**.
