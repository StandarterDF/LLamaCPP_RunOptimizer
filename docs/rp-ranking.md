# Рейтинг RP-моделей: Thinking / Non-Thinking

Сводный рейтинг: какие модели лучше «в роли» по нашему RP-харнессу — отдельно для думающего
(**Think**) и обычного (**NoThink**) режима. Это витрина по одному числу; разбор, цитаты и сырые
данные — в `docs\rp-quality-eval.md` и `docs\models.md`.

- **Общий рейтинг (RP-средний)** — среднее по 8 осям LLM-судьи, шкала 1–5:
  ум · память · персонаж · инструкция · инициатива · русский · проза · повторы.
  Судья — `gemma-4-26B-A4B-it-UD-IQ3_XXS`, агрегатор — `bench\quality\judge_score.py`.
- **Qwen** — второй, более строгий судья (`Qwen3.6-35B-A3B` MXFP4, ~3.3 против ~4.4 у Gemma),
  есть только у моделей полного набора.
- Стенд: RTX 4060 Ti 16 ГБ, сборка b11382 (CUDA 12.4); сэмплинг — лучший из `.bat` модели
  (RU-safe temp0.6 / min-p0.1 / top-k0 для полного набора).

## Как читать (важно)

1. **Баллы сравнимы только внутри одного набора сценариев и одного судьи.** Полный набор (6 сценариев)
   строже: те же модели на 2 сценариях получают на **0.2–0.4 выше** (DTV2 Think: 4.97 → 4.55).
   Поэтому в каждой таблице два блока: **«6 сценариев»** (сопоставимо между собой) и
   **«только 2 сценария»** (числа завышены — с первым блоком напрямую не сравнивать).
2. **Qwen-колонку** сравнивать только между собой (другая шкала строгости).
3. **N** — сколько ответов судья выставила оценку; пустые ответы think-режима не оцениваются,
   поэтому «Чисто 100 %» у Think может включать пустышки (см. `rp-quality-eval.md` §7).
4. Итог по модели (все режимы, как в `models.md`): DTV2 4.55 · Schattenblume 4.55 · StyleTune 4.40 ·
   Giftige-Blume-v1 4.39 · Goetia 4.23 · Glistening 4.13.

## 3. Рабочий вывод

- **Режим по умолчанию — NoThink.** У многих 31B-мержей Think сломан в llama.cpp: пустые ответы
  (незакрытый `<channel|>`), утечка reasoning в текст, у Blume безлимит бюджета качества не добавил.
  Исключение — DTV2/Schattenblume, где Think реально сильнее и чище.
- **Лучшая связность и русский** — DTV2 и Schattenblume (один класс; при прямом сравнении чуть впереди DTV2).
- **Лучшая инициатива** (модель двигает сцену, а не «говорит головой») — **Giftige-Blume-v1**.
- **Быстрые варианты** — StyleTune-26B (~63–66 t/s), Goetia-26B-A4B (~73 t/s), Glistening-NoThink (~23 t/s).

> Это наши измерения, а не вкусовой рейтинг. Итоговый выбор «под себя» (характер, стиль, ERP) —
> за пользователем; здесь только то, что подтверждено харнессом и судьями.
